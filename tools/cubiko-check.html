Cubiko check

This page asks your Cubiko what it is and how it's set up, then saves a report for Staffy CNC. It reads only. The machine moves only if you choose step 6.

This browser can't talk to USB machines. Open this page in Google Chrome or Microsoft Edge.

1 Connect the machine

Plug the Cubiko into this computer with its USB cable and switch it on. Then press Connect and choose the entry that says USB-SERIAL CH340 (or similar) from the list.

2 Ask the machine about itself

Staffy will ask for the firmware version, every setting, and the current position. Takes a few seconds.

3 Check the buffer size

Staffy needs to know how much the machine can hold in memory while cutting. This briefly changes one report setting ($10) and puts it back straight away. Nothing moves.

4 Test the switches by hand

Press Start, then gently press each limit switch with your finger, and touch the probe clip to the probe plate. Each light turns green when the machine notices. Nothing moves.

5 Save the report

Save the file and send it to Claude (drag it into the chat). That's the test done.

6 Optional: test homing

Homing makes the machine move until it finds its switches. Only do this if you're comfortable.
